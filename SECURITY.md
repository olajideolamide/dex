# Security Policy

Security issues are taken seriously. If you think you've found a vulnerability in DEX, please help us handle it responsibly.

## Supported Versions

Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

Please do not open a public issue.

Preferred reporting path:

- [Report a vulnerability via GitHub Security Advisories](https://github.com/olajideolamide/dex/security/advisories/new)

In your report, include:

- A clear description of the impact
- Steps to reproduce (or a minimal proof of concept)
- The DEX version, PHP version, and CodeIgniter version
- Any suggested mitigation or patch ideas (if you have them)

## Coordinated Disclosure

We'll confirm receipt, investigate, and work on a fix. Once a patch is available, we'll coordinate a release and publish a short advisory describing the issue and affected versions.
